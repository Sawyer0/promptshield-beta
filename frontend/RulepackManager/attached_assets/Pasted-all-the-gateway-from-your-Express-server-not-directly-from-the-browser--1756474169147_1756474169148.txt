- Mint a short-lived RS256 JWT per proxied request:                                                                  
    - Load private key: PS_BFF_JWT_PRIVATE_KEY (keep private; never expose to browser).                              
    - Claims required by the gateway:                                                                                
    - `sub`: user ID (UUID/string)                                                                                   
    - `name` or `email`: user display name or email                                                                  
    - `tenant_id`: active tenant UUID string                                                                         
    - `iss`: must match `PS_BFF_JWT_ISSUER`                                                                          
    - `aud`: must match `PS_BFF_JWT_AUDIENCE`                                                                        
    - `exp`: 30–120 seconds in the future (short TTL)                                                                
- Send as Authorization: Bearer <jwt> on the request to the Go gateway.                                              
- Minimal Express helper (pseudo-code):                                                                              
    - Sign with RS256 using your private key.                                                                        
    - Attach Authorization header to the outgoing request to the gateway.                                            
    - Example endpoints to proxy: /rulepacks, /admin/tenants, /admin/system/*, /api/v1/services/*, etc.              
                                                                                                                     
Gateway environment to set                                                                                           
                                                                                                                     
- PS_BFF_JWT_PUBLIC_KEY: PEM public key (matching Express private key).                                              
- PS_BFF_JWT_ISSUER: e.g., promptshield-bff.                                                                         
- PS_BFF_JWT_AUDIENCE: e.g., promptshield-gateway.                                                                   
- PS_BFF_JWT_LEEWAY: optional skew, e.g., 60.                                                                        
- Optional CORS: PS_CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173.
