Here’s exactly what to put in those three frontend secrets and how to generate them.                                 
                                                                                                                     
Values to use                                                                                                        
                                                                                                                     
- PS_BFF_JWT_PRIVATE_KEY: Your BFF’s RSA private key in PEM (PKCS#8) format. Paste the full multi‑line value         
including the BEGIN/END lines.                                                                                       
- PS_BFF_JWT_ISSUER: A stable identifier for your BFF, e.g. promptshield-bff or https://your-app.example.com/bff.    
- PS_BFF_JWT_AUDIENCE: A stable identifier for the Go gateway, e.g. promptshield-gateway.                            
                                                                                                                     
Generate keys (dev)                                                                                                  
                                                                                                                     
- Create an RSA key pair:                                                                                            
    - openssl genpkey -algorithm RSA -out bff_private.pem -pkeyopt rsa_keygen_bits:2048                              
    - openssl rsa -in bff_private.pem -pubout -out bff_public.pem                                                    
- Set frontend secrets:                                                                                              
    - PS_BFF_JWT_PRIVATE_KEY: contents of bff_private.pem                                                            
    - PS_BFF_JWT_ISSUER: promptshield-bff-dev                                                                        
    - PS_BFF_JWT_AUDIENCE: promptshield-gateway-dev                                                                  
- Set backend (Go) env to match:                                                                                     
    - PS_BFF_JWT_PUBLIC_KEY: contents of bff_public.pem                                                              
    - PS_BFF_JWT_ISSUER: promptshield-bff-dev                                                                        
    - PS_BFF_JWT_AUDIENCE: promptshield-gateway-dev                                                                  
    - Optional: PS_BFF_JWT_LEEWAY=60                                                                                 
                                                                                                                     
Notes                                                                                                                
                                                                                                                     
- Keep the private key only in the frontend BFF (Express). Never ship it to the browser or commit it.                
- The issuer/audience are just strings but must match exactly on both sides.                                         
- The jose library expects PKCS#8; the command above produces that, so import works with importPKCS8(..., 'RS256').  
- For production, generate a new pair and use different ISS/AUD (e.g., promptshield-bff and promptshield-gateway     
without -dev).                                                                                                       
                                                                                                                     
Example PEM (for reference)                                                                                          
                                                                                                                     
- Private key field must look like:                                                                                  
    - -----BEGIN PRIVATE KEY-----                                                                                    
    - base64 lines…                                                                                                  
    - -----END PRIVATE KEY-----
