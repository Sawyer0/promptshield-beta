Protecting Data in Transit 

PS communicates with external LLM APIs, which means sensitive prompts are leaving our 
user's environment and traveling across the internet. This creates several attack vectors we 
need to address. 

●  Ensure all API communications use TLS encryption 
● 

Implement certificate pinning for the LLM providers we support (e.g OpenAI, Anthropic) 
to prevent man-in-the-middle attacks 
Implement prompt sanitization before transmission. By stripping out obvious PII or 
sensitive patterns before sending data to external services 
Implementing a "privacy-first" scanning mode where the tool performs local regex and 
keyword scanning first, and only sends prompts to external LLMs if they pass certain 
safety thresholds.

●
