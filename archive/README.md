# Archived CLI (Marker)

This repository is transitioning from a CLI + Enforcer to a gateway/enforcer-only service.

For now, no files have been removed or moved. The current CLI and related code remain in place under `cmd/` and docs under `docs/CLI.md` so we can refer back to them if needed.

When we finalize the migration, we can either:
- Create an `archive` branch from the current state, or
- Move the CLI tree into `archive/cli/` and update references.

Until then, treat this directory as a marker that the CLI is considered archived and will not receive new features.
